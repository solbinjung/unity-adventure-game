# 🧭 유니티 어드벤처 게임 프로젝트 (Unity Adventure Game Project)

> **개발 기간:** 2023.06

유니티(Unity) 엔진의 핵심 컴포넌트 시스템과 C# 객체 지향 프로그래밍의 기초를 학습하며 제작한 **3D 액션 어드벤처 게임**입니다. 플레이어가 맵을 탐험하며 장애물을 돌파하고 목적지에 도달하는 핵심 루프를 구현했습니다.

---

## ✨ 주요 구현 특징 (Key Features)

### 1. 플레이어 컨트롤 및 물리 동기화
* `Rigidbody`와 유니티 런타임의 물리 연산을 활용하여 미끄러짐 없는 안정적인 캐릭터 이동 및 [점프 / 대시] 메커니즘 구현
* `Input.GetAxis` 기반의 키보드 입력 매핑을 통한 자연스러운 가속도 및 방향 전환 제어

### 2. 상호작용 및 아이템 수집 시스템
* `Collider`의 트리거 이벤트(`OnTriggerEnter`)를 활용하여 맵에 배치된 수집형 아이템(코인, 열쇠 등) 및 장애물과의 충돌 판정 처리
* UI 시스템(`Canvas`)과 데이터를 연동하여 플레이어가 획득한 아이템 수량을 실시간으로 화면에 동기화

### 3. 스테이지 플로우 및 씬 매니지먼트
* `UnityEngine.SceneManagement` API를 활용하여 게임 시작 화면, 메인 스테이지, [게임 오버 / 클리어] 화면 간의 유연한 씬(Scene) 전환 구조 구축
* 특정 목적지 트리거 도달 시 다음 레벨로 데이터 손실 없이 안전하게 이동하는 레벨 오버랩 구조 학습

---

## 🚀 이 프로젝트를 통해 얻은 성장 (Retrospective)

* **컴포넌트 기반 설계(Component-Based Design) 이해:** 유니티의 `GameObject`와 컴포넌트 아키텍처를 이해하고, 스크립트를 독립적인 모듈로 분리하여 재사용하는 기초 역량을 틔웠습니다.
* **상태 머신(State)의 필요성 인지:** 캐릭터의 상태(Idle, Run, Jump 등)가 많아질 때 조건문 분기가 복잡해지는 한계를 경험하며, 이후 프로젝트(`GTen`, `Shadow of the Dragon`)에서 더 발전된 애니메이션 상태 머신(Animator Controller)과 싱글톤 패턴을 주도적으로 도입하게 된 중요한 계기가 되었습니다.
